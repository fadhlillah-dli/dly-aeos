# DLY AEOS — DLY AI Engineering Operating System

Local-first control plane for AI-assisted software engineering. One product, one control plane:
humans choose the domain (PERSONAL or OFFICE), approve concrete plan versions and own merge and
production; a deterministic controller enforces scope, access, cost and state; eligible low-cost
workers execute tasks; the official Claude Code client (Claude Max) supervises checkpoints.

The authoritative design is [docs/architecture/DLY_AEOS_Master_Architecture_Final.md](docs/architecture/DLY_AEOS_Master_Architecture_Final.md).
Status of every capability is tracked with explicit evidence levels — nothing in this repository
claims a capability is working unless the Readiness Doctor or a recorded test proves it.

> Status: bootstrap (M0). See the implementation coverage matrix once published in `docs/`.
