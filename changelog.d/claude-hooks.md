### Added

- **Claude Code secret guard and session facts hooks.** `scripts/claude_hooks/secret_prompt_guard.py` is a fail-open `UserPromptSubmit` hook: a prompt carrying a high-confidence secret shape (the token patterns of `aeos.core.redaction`, plus an `ASIA` AWS key id and a bare PEM private key header it does not cover yet) is blocked before it reaches the model, with a bilingual message that names only the kind, says to store it with `./aeos secrets set` and to rotate anything already sent, and keeps the text out of the block message (`suppressOriginalPrompt`). Any internal error exits 0 silently. The `SessionStart` hook prints `scripts/preflight.py --facts`. Prevents the incident class of 2026-10-26 (a vault unseal key pasted into chat twice). Evidence: E2 unit and subprocess bite tests on macOS arm64 (every kind blocked and the reason free of the value; git SHA, UUID, digest, placeholder, short prefixes, dotted identifiers and bad JSON pass). NOT-PROVEN on Windows and Intel macOS, and NOT-PROVEN inside a live Claude Code session (the hook protocol was read from the documentation, not exercised).
