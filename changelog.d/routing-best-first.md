### Changed

- **Best-first route selection under load (ADR-0124, owner decision R31 of 2026-10-28).** Routing now ranks eligible worker routes by tier, evaluation score, the implementing agent's `route_policy.preferred_routes` (it only re-orders routes that already passed every hard filter, so a preferred `:free` route never serves INTERNAL work and a WATCHLIST or unbudgeted paid route is never chosen), priority and key. Decision C' amends ADR-0041 decision C: for PUBLIC tasks the OpenCode Go subscription routes ($0 marginal within the plan) rank first and the free OpenRouter routes are the fallback; the new setting `go_public_share` (default 0.5) caps PUBLIC's share of each Go route's 5h window so INTERNAL work is not starved. A Go route admits a task only when its estimated allowance (this instance's median per route and role, else the LiveBench 2026-10-25 cost of one long agentic task, else half the window; never more than the whole window, so a Pro Go route whose prior exceeds its window still takes a task on an empty window) fits the 5h window minus recorded usage and the holds of in-flight runs (`ALLOWANCE_FIT`); a 429 or provider 5xx starts a cool-down on the route's quota state (60 s doubling to 30 min, or a longer Retry-After; a later 429/5xx never shortens a recorded reset) that new tasks skip while a running attempt keeps its route; per-route, Go-wide and OpenRouter-free concurrency caps skip a busy route (`ROUTE_BUSY`). These load rules hold for an evaluation-bound task too, and admission enforces the selected route's capacity answer. After any skip only a $0-marginal route may serve, otherwise the task waits (`ROUTE_CAPACITY`): never a paid route. A quota-stopped task moves between attempts only when its wait exceeds `route_reselect_after_minutes` (default 30) and only to a $0-marginal route. New settings: `go_public_share`, `route_max_active`, `go_max_active_total`, `openrouter_free_max_active`, `route_reselect_after_minutes` (all outside the route configuration identity; caps 1..2, HARD_MAX_ACTIVE stays 2). The worker prompt revision, the policy version and every seeded route's configuration hash are unchanged (pinned in a test), so no ACTIVE TRIAL is voided. Evidence E2 (unit bite tests on macOS arm64); NOT-PROVEN on Windows and Intel macOS until CI runs them, and that Go answers a limit with HTTP 429.
