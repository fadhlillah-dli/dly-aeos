### Added

- **Docs-versus-code contract tests.** Four new checks keep the docs true to the code: `tests/unit/test_docs_commands.py` (every `scripts/<name>.py` and `--flag` written in the docs exists, read with `ast`, and every `aeos <command>` is a registered CLI command), `tests/unit/test_env_contract.py` (every `AEOS_*` variable the code reads, also inside the verifier plugin source embedded in a string, has a row in the new "Environment variables" table of `docs/OPERATIONS.md` with a "Source" column that matches its readers, or an exemption with a reason; every row is read by something; every operation that calls `refuse_worker_context` is listed), `tests/unit/test_ci_contract.py` (the "CI layout" section of `CONTRIBUTING.md` names every job of `ci.yml` and only real ones; every script with a `--check` flag is run with it by a `run:` step of CI, `scripts/gates.py` or a test, read from code and not from comments, and a test must call `main` on the module it loaded from that script). The `aeos` command resolver moved to `tests/unit/docs_contract_support.py` and the VS Code task test uses it.
