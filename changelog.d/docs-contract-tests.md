### Added

- **Docs-versus-code contract tests.** Four new checks keep the docs true to the code: `tests/unit/test_docs_commands.py` (every `scripts/<name>.py` and `--flag` written in the docs exists, read with `ast`, and every `aeos <command>` is a registered CLI command), `tests/unit/test_env_contract.py` (every `AEOS_*` variable the code reads has a row in the new "Environment variables" table of `docs/OPERATIONS.md`, and every row is read by something), `tests/unit/test_ci_contract.py` (the "CI layout" section of `CONTRIBUTING.md` names every job of `ci.yml` and only real ones; every script with a `--check` flag is run with it by CI, `scripts/gates.py` or a test). The `aeos` command resolver moved to `tests/unit/docs_contract_support.py` and the VS Code task test uses it.
