### Security

- **A BUDGET decision covers exact route keys only.** `aeos policy decide --scope routes=a,b` stored the scope as text, and the route check tested `route_key in routes` on it, a substring test: a BUDGET naming `opencode-go/kimi-k3.1-pro` also covered `opencode-go/kimi-k3`, and one naming an OpenRouter `:free` key covered its paid twin. The OpenCode Go pool-move guard read only list scopes, so a text-scoped BUDGET did not stop a move. One reader, `scope_route_keys` in `aeos.routing.service` (also on the routing facade), now turns `auth_scope.routes` into a list of exact keys (a list stays a list of stripped strings, text is split on commas, anything else names no route); the budget check and the pool-move guard use it, and the CLI stores `routes=` as a JSON list. Bite tests in `tests/unit/test_routing_budget_scope.py` are red on the previous code with their own messages; near misses (a targeted BUDGET, a longer key that only contains the route key) are green. Found by review before any spend (LESSONS L27). Evidence E2 (unit run on macOS arm64); NOT-PROVEN on Windows and Intel macOS until CI runs them.
