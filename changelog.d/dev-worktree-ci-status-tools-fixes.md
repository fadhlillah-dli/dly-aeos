### Fixed

- **Worktree and CI status tools: three review defects.** `worktree.py remove --unlink-links` no longer counts the files git lists below a junction as uncommitted changes (Git for Windows reports a junction as a plain directory and walks into it, so every junction that was not gitignored made the removal refuse); `ci_status.py --wait` no longer polls again sooner than the 30 s interval before the deadline (it sleeps the time left and reports TIMEOUT); an unwritable `--report` path now ends with one `CI: ERROR <sha>` line and exit 2 instead of a traceback that a watcher reads as RED. Evidence: E2 unit tests run on macOS arm64 (a real directory in a temporary repository reproduces the Windows view of a junction; poll-spacing and unwritable-report bite tests with near-miss controls). The Windows junction removal itself is NOT-PROVEN until a Windows run passes.
