### Added

- **Usage value report (`aeos usage report`, `GET /api/usage/report`).** A read-only PERSONAL report that answers the owner's question whether the two $10 plans are used well (owner request R34, 2026-10-28): OpenCode Go allowance used per route in the trailing 5h window, the week and the month against the seeded allowance (percent, totals marked as a lower bound when calls cannot be counted, routes never used), OpenRouter free requests today and paid spend per route and role with the owner BUDGET and the key limit, work per role (verifier pass rate per route and role, paid admissions by ESCALATION or OVERFLOW reason, median wall-clock per plan) and Claude (measured by ccusage outside AEOS; an optional `ccusage_export_path` export is read for token totals, never dollars). It writes nothing, calls no network and outputs no task text, error text, event payload or secret; an OFFICE session is refused (`USAGE_REPORT_PERSONAL_ONLY`). Evidence: E2 unit tests on macOS arm64 with a seeded temporary database (figures, a differential OFFICE test, a no-write and no-network guard, a no-private-text check, API and CLI). NOT-PROVEN on Windows and Intel macOS.
