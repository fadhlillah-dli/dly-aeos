### Added

- **A fixed timing bound in a test states its margin.** A fixed time bound measures the machine, not the code: on 2026-10-28 three timing tests failed with correct code (a 200 ms wall-clock bound under load, a 0.5 s CPU bound on the Intel macOS runner that took 0.54 s there and 0.13 s on arm64, and a bite test whose 0.3 ms runs were noise), LESSONS L15. `tests/unit/test_timing_bounds_declared.py` AST-scans every `tests/**/*.py` file and fails, with `<path>:<line>: fixed timing bound without a '# timing-cap: <margin>' comment`, on an `assert` that compares a measured time with a fixed bound unless a `# timing-cap: <margin>` comment of at least 10 characters sits on the assert's line or directly above it. A measured time is a `time.perf_counter`, `monotonic`, `process_time` or `time` call (and `_ns` variants, bare imports and module aliases), a name assigned from one in the same function to a fixed point, a list or dict filled with one, or the result of a helper of the same file that returns one (for a returned tuple only the timed element). Comparisons whose both sides are measured (ratios, deadlines) are allowed, polling loops are not asserts, and a fixed-bound comparison moved out of the assert (`slow = [...]`, `assert not slow`) still counts. Bite tests in a temporary directory are red with their finding text (a plain bound, a best-of helper on CPU time, the timed element of an unpacked tuple, a bound inside `and`, bare and aliased imports, a bound moved out of the assert, a cap that is too short, two lines up or inside a string) and green for the near misses (a declared cap, a ratio, deadline polling, a helper verdict, the untimed sibling of an unpacked tuple). The 15 existing fixed bounds on main were measured on macOS arm64 (load average 3 to 10) and each now states its margin; two changed: the detached-survivor test in `test_verification_procs.py` compares against the grace period it rules out instead of an arbitrary 1.0 s, and the ReDoS test in `test_owner_commands_paste_safe.py` allows 5 s instead of 0.5 s wall clock (a match takes about 15 us; the old regex doubled per repeat and never returns at 40). `CONTRIBUTING.md` states the rule and prefers relative checks. Evidence E2 (unit run on macOS arm64); NOT-PROVEN on Windows and Intel macOS until CI runs them.
