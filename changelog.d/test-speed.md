### Changed

- **Faster backend test suite, same assertions.** Shared fixtures: `tests/conftest.py` builds one migrated template database per test process (tables, append-only triggers, alembic head stamp) and gives every test its own copy through SQLite's online backup, so each test still starts from a fresh, isolated database (also under pytest-xdist: one template per worker). The Argon2id hasher is wrapped once per session by a memo that still runs the real production-parameter hasher once per distinct password and (hash, password) pair. Test-local: DOCX conversion is stubbed in the publisher job and concurrency fixtures (one real end-to-end conversion is kept), git and release repositories are copied from one real template per process, the worker-runtime executor tests fingerprint a two-file controller (one test keeps the real checkout), the scripted containment report is built once per process and handed out as a copy, `--collect-only` children in `test_ci_shards.py` are shared, and the invalid-`--shard` test runs pytest in process. `test_doctor_seams.py` uses a cheap file-local hasher and runs the real HTTP guard probe once per guard fingerprint.
- **Product memoisation, keyed on the input.** `secrets.installer._manifest_entry` still reads `install-manifest/manifest.yaml` on every call and reuses only the YAML parse of byte-identical text (bounded `lru_cache`), returning a deep copy. `routing.service.current_policy_version` hashes `policy/*.yaml` through the new `policy.snapshot.policy_file_hashes` (the same hashes `load_policy_files` records, so the `pol-...` value is identical); each file is read once as bytes, hashed and decoded as UTF-8, and its YAML parse is remembered per distinct text, so a file that is not UTF-8 or whose parse raises (RecursionError) still gives `None` (binding drift fails closed) exactly as before. `claude_bridge.parsing.validate_schema` remembers (bounded, 256) the canonical JSON of schemas that passed `check_schema`; failures and schemas that do not round-trip through JSON exactly are always checked. `worker_runtime.scope.matches_any` normalizes the path once and compiles each distinct pattern set once (a pattern list with a non-`str` element takes the original first-match loop, so its results and errors are unchanged). `tests/unit/test_perf_memoisation.py` proves that a changed input is re-read (also a same-size rewrite), that callers cannot mutate a cached object, that an invalid schema is never remembered as valid and that a manifest text that does not parse is cached as `None` only for that exact text, and that `matches_any` equals the per-pattern loop.
- **Measured** on one Apple Silicon Mac, one run at a time, 1-minute load average 2.4 to 4.1 (always below 6), baseline = a clean checkout of 7fc8182. Full unit suite `pytest -n 4 tests/unit`: baseline 380.7 s (load 2.69) and 377.4 s (load 2.42); this branch 324.1 s (3.20), 327.4 s (3.72) and 340.3 s (3.93), about 12 percent faster.
