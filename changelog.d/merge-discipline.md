### Added

- **Written merge procedure and a release tag check.** `CONTRIBUTING.md` has a "Merging" section (merge only on a GREEN `ci_status.py --pr <n> --expect-sha <sha> --required-only --wait --deadline 25`, check `main` with `--after-merge`, merge nothing while `main` is RED, re-run only for INFRA, update the branch instead of re-running when the base moved, one concern per pull request); the delegation brief rule 12 and the bite-test step of the lessons register carry the short form ("red for the right reason"). `ci_status.py --pr` prints `HINT: main moved since this run (approximate <old>..<new>); update the branch, do not re-run.` before a RED verdict when the base branch has newer commits than the creation time of the original workflow run, which a re-run does not change (read-only calls, never for GREEN, the verdict stays the last line; the range is approximate because the workflow run object's `pull_requests[]` was empty for runs of closed pull requests and is unmeasured for an open one, so the time heuristic is used and `base.sha` is not). New `scripts/release_check.py --tag vX.Y.Z` reads the tagged commit and checks that the tag equals the version in all five version sources (the list is shared with the hygiene test, which is now the only version-equality test and covers `backend/aeos/__init__.py` too), `CHANGELOG.md` has the heading, `changelog.d/` holds only its README, the release notes exist and the commit is an ancestor of `origin/main`; its last line is `RELEASE_CHECK: PASS` or `FAIL`. Evidence: E2 unit tests on macOS arm64 against fixture JSON and temporary git repositories (a differing source, a leftover fragment, a missing heading, missing notes and a tag off main are each red with their own message, the consistent repository is green). NOT-PROVEN: the hint against the live GitHub API (including `pull_requests[]` of an open pull request's run), that a re-run builds the old test merge commit in this workflow (GitHub documents the same `GITHUB_SHA`/`GITHUB_REF`), and everything on Windows and macOS Intel until CI runs it.
