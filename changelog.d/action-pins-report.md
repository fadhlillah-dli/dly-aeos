### Added

- **Monthly report of pinned actions and binaries (`scripts/action_pins.py --report`), and the UI smoke server on the null keyring.** Workflow pins never move by themselves and ADR-0115 allows no automatic Dependabot pull requests (they would not carry the owner identity), so the report lists every `uses: owner/repo@<sha> # vX` of `.github/workflows` and the pinned `actionlint` release with its SHA-256, finds through the GitHub CLI the newest release published at least 14 days ago and the commit of its tag, and prints one row per pin (for an action update also the full 40-hex commit of the new tag, `newest_sha` in `--json`): `CURRENT`, `UPDATE <tag>` or `UNKNOWN (reason)` (no version comment, a tag that does not point at the pinned sha, a failed lookup). It exits 0 always; the last line is `ACTION_PINS: <n> pins, <k> updates available`; `--json`, `--today` and `--workflows` exist for tools and tests. An update stays a normal pull request (new sha and version comment, and for a binary the SHA-256 from the release's checksums file). `tests/unit/test_delivery_ci_secrets.py` now fails when a pin has no version comment and checks that the tool reads the same pins as the parsed YAML. Separately, the browser e2e smoke server (a real uvicorn child outside the SecretGuard) now selects the null keyring through `PYTHON_KEYRING_BACKEND`, so even an integration run never queries the macOS Keychain or Windows Credential Manager (LESSONS L20); the SecretGuard docstring no longer lists it as not covered. Evidence: E2 unit tests on macOS arm64 against fixture JSON (a pin behind is `UPDATE` with the tag, a release 13 days old is ignored while one exactly 14 days old counts, a missing version comment is `UNKNOWN` with its reason, a current pin is `CURRENT`; the smoke child's keyring is the null backend with the variable and OS detection without it), plus one live read-only run on the real workflows (6 pins, 0 updates). NOT-PROVEN: the smoke run itself with the null keyring (it needs the browser job; reasoned only) and everything on Windows and macOS Intel until CI runs it.
