### Fixed

- **A planner's tool names no longer stop every worker task.** The first live plan named its tools `read_file`, `write_file`, `run_tests` and `git_diff`; routes record the reviewed set as `fs.read`, `fs.write:allowed_paths` and `tests.run`, so every route refused every task (`ROUTE_INELIGIBLE`) and no worker started. `aeos.core.tool_names` maps the synonyms that mean exactly one reviewed capability onto it (never widening one), the compiler stores the reviewed names, and routing compares with them (so tasks compiled before this fix are served too); the planning schema stays unchanged because its JSON must fit the Windows command line. Unknown tools are kept as written and still refuse the route by name (LESSONS L29). Evidence: E2 unit run on macOS arm64; four new tests red before; on a copy of the live database the plan's tasks go from 0 to 21 eligible routes.
